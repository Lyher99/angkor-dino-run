# Angkor Dino Run

A Chrome-Dino-style endless runner with High-Detail Khmer pixel-art assets built using [`pxl`](https://github.com/crsolver/claude-pxl).

## Play Online (GitHub Pages)
Enable **Settings -> Pages -> Deploy from branch (`main` / `(root)`)** to play at:
`https://Lyher99.github.io/angkor-dino-run/`

## Features
- **Level 1 — Angkor Wat Sunrise:** 5-tower lotus-bud Angkor Wat parallax background + **Royal Khmer Dino** (`dino_run`, `dino_duck`, `dino_jump`).
- **Level 2 — Bayon Twilight (unlocks at 300 pts or toggle in header):** Starry twilight sky, Bayon stone-face towers + **Golden Khmer Singha** (`singha_run`, `singha_duck`, `singha_jump`).
- **Obstacles & Collectibles:** Carved Angkor Pillars, 3-headed Naga statues, flying Garudas, and Sacred Lotuses (+50 pts).

## Controls
- `Space` / `↑` / `W` / Click: Jump
- `↓` / `S`: Duck & Fast-Fall
